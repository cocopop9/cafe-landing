# ☕ Bean & Bloom 카페 랜딩 페이지

가상의 동네 스페셜티 카페 **Bean & Bloom**을 소개하는 간단한 한 페이지짜리 웹사이트입니다.
HTML과 CSS만으로 만들었으며, 별도의 빌드 과정이나 라이브러리 없이 바로 열어볼 수 있습니다.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| 상단 메뉴 | 로고와 섹션 이동 링크 (소개 · 메뉴 · 오시는 길) |
| 메인 배너 | 커피 사진 배경과 대표 문구, "메뉴 보기" 버튼 |
| 우리의 이야기 | 카페 소개와 특징 3가지 (직접 로스팅, 베이커리, 편안한 공간) |
| 대표 메뉴 | 커피·디저트 6종과 가격 |
| 오시는 길 | 주소, 영업시간, 연락처 |
| 하단 | 저작권 표시 |

## 파일 구조

```
cafe-landing/
├── index.html   # 페이지 구조와 내용
├── style.css    # 디자인 (색상, 레이아웃, 모바일 대응)
└── README.md    # 이 설명 파일
```

## 실행 방법

`index.html` 파일을 웹 브라우저로 열면 됩니다.

> 메인 배너의 배경 사진은 Unsplash에서 불러오므로 인터넷 연결이 필요합니다.

## 참고

- 카페 이름, 주소, 전화번호, 메뉴와 가격은 모두 예시용 가상 정보입니다.
- 화면 폭이 좁은 휴대폰에서도 보기 좋도록 반응형으로 만들었습니다.
